# Enterprise E-commerce Data Engineering Lifecycle

This repository captures the end-to-end data engineering lifecycle for a mock enterprise e-commerce platform. It includes a Draw.io diagram and a system manifesto tracing data states across generation, ingestion, storage, transformation, and serving.

## Files

- `prac1.dio` — Draw.io diagram file showing the lifecycle stages and cross-cutting lifecycle concerns.
- `data_engineering_manifesto.md` — Documentation for the data flow, schema artifacts, security, observability, and privacy considerations.

## Notes

- Diagram covers transactional DB entities, clickstream JSON payloads, and third-party inventory log streams.
- Architecture emphasizes data state transitions from source systems through ingestion, storage, transformation, and consumption.
